The team name, the challenge, the app address, the members, the n8n project and the AI model endpoint come from the tool `team_info`.

Names in n8n:

- Webhook and form paths start with the slot id, for example `team-07-search`. A path can be active only once in the whole n8n instance.
- Workflow, Data Table and folder names start with the slot id as well, for example `team-07 · Search`: all teams on your challenge share the n8n account. Change only your own; the connection refuses changes to the others.
- Workflow files in this repository: `workflows/<short-name>.json`.
